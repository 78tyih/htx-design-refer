# Assets

This folder contains non-font visual assets extracted or optimized from the user-supplied HTX Skills for reference/workflow continuity.

Included:
- approved HTX mark SVG variants supplied by the user;
- an optimized repository preview of the blue-grid background;
- the exact soft-blue-white SVG background;
- optimized repository previews of the Huobao character and dollar-coin references;
- the exact time icon SVG.

Large raster assets are stored here as **optimized reference copies** for repository portability and README/Agent preview. The source originals remain inside the user-supplied `.skill` packages used to build this Design Refer.

Font binaries are intentionally excluded from this repository. Production environments should use appropriately licensed/local copies of Urbanist and HarmonyOS Sans SC.
