# Assets

This folder contains non-font visual assets extracted from the user-supplied HTX Skills for reference/workflow continuity.

Included:
- official mark SVG variants supplied by the user;
- approved blue-grid and soft-blue-white backgrounds supplied by the user;
- Huobao and dollar-coin reference images supplied by the user;
- time icon supplied by the user.

Font binaries are intentionally excluded from this project package. Production environments should use appropriately licensed/local copies of Urbanist and HarmonyOS Sans SC.
