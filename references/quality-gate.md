# HTX Design Quality Gate

Score each item 0 / 1 / 2. Recommended pass: 16/20, with no hard red flag.

1. **Brand color fidelity** — correct HTX blue/gold/neutral usage.
2. **Semantic hierarchy** — primary title/value/body/auxiliary information are clearly separated.
3. **Copy fidelity** — no unsupported rewrite or invented label.
4. **Typography discipline** — correct 400/500/700 hierarchy; no unsupported heavy/italic styling.
5. **Safe-area discipline** — content and logo zones are respected.
6. **Family fidelity** — selected visual family is recognizable and not mixed indiscriminately.
7. **Background integrity** — approved asset is not stretched or arbitrarily recolored.
8. **Asset integrity** — logo / mascot / supplied imagery is not distorted or recolored.
9. **Decorative restraint** — no unnecessary glow, geometry, nodes, badges or filler.
10. **Medium fitness** — poster, long-form, UI or deck behavior matches the medium.

## Hard red flags

Any one requires revision:

- official logo is distorted, recolored or wrongly placed;
- user copy is silently rewritten or fabricated;
- Huobao identity / clothing / body integrity is broken;
- background is non-uniformly stretched;
- unreadable or clipped text;
- generic neon/cyberpunk crypto aesthetic replaces HTX brand logic;
- unapproved decorative elements become the primary identity.
